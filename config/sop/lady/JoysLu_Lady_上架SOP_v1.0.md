## 2. 標題

### 2.1 硬規則

- **上限 60 字**（含空格）；目標 **58-60**，55-57 可接受；補不到就留短，**不用形容詞灌水**
- 半形空格唯一分隔；**零符號**（不用 🏆、!、【】、｜、emoji）
- **不放品牌標籤【JoysLu Lady】、不放商品編號**（H-c53 這種一律不寫）
- **不寫**免運／隔日到貨／出貨速度／現貨／預購（備貨天數在商品頁本來就看得到）
- 不寫商品沒有的屬性；尺碼數字只寫程式給的（公斤範圍），不自己編胸圍腰圍
- ⚠️⚠️ **只放「這支商品本身就是」的品類詞**：同一類的詞裡混著不同款式（女裝-褲 同時有
  工裝褲／吊帶褲／西裝褲／連身褲），闊腿褲的標題寫上它們就是不實標示，引來的點擊也不會轉換。
  **寧可短也不要湊字數**（2026-09-18 首跑實際發生：亞麻闊腿褲被補上工裝褲／吊帶褲／西裝褲）
- 不放單字詞（女、褲）
- 繁體，不可出現簡體、產地字眼、其他平台名

### 2.2 公式

```
[最大詞] [第二大詞] [這支商品的真實形態詞] [依搜尋量降冪補到 58~60 字]
```

- 前兩格＝該品類搜尋量最大、**而且真的描述這支商品**的詞（程式會給【第一行大詞候選】）
- 第三格＝這支自己的名字（冰絲丁字褲／分段壓力長筒襪／莫代爾蕾絲邊三角內褲），**每支不同**，避免自家互搶同一字串
- 定稿範例（9/17 換版那 8 支）：
  `丁字褲 無痕內褲 冰絲丁字褲 性感內褲 女內褲 女生內褲 女性內褲 冰絲內褲 性感丁字褲 無痕丁字褲 透氣內褲 丁字褲女`
  `絲襪 黑絲 透膚顯瘦連褲絲襪 隱形絲襪 絲襪不易破 透膚絲襪 黑絲襪 0d超薄絲襪 褲襪 顯瘦絲襪 連褲襪 長絲襪 女襪`
- 倒裝雙放是可以的（`女內褲`／`內褲女` 是兩個字串、各有各的量）

### 2.3 詞只能用搜尋詞庫給的

每次生成會附【可用關鍵字】【第一行大詞候選】【建議尾串】，已排除他牌品牌詞、錯字詞、死詞。
**只能用清單裡的詞**，沒列的不要自己發明。情趣／性感類的詞 Edwin 2026-09-17 確認可用。

## 3. 詳情（中間版本，同 Nail）

程式搭框架、只填有把握的，其餘由人在待上架區補。**你只寫前三段**：

1. **✦ 商品特色** 2-3 行，只根據商品名與屬性表（材質、版型、機能），不誇大
2. **✦ 商品規格** 只列屬性表或商品名明確寫到的（材質成分、厚薄、彈力、版型）；
   **尺寸只寫程式給的尺碼標籤（S/M/L 與公斤範圍），不要自己編胸圍腰圍數字**；沒資料整段省略
3. **✦ 穿搭與洗滌** 3-5 行，怎麼搭、洗滌注意；不編廠商沒寫的機能

下面兩段**程式會自己補，不要寫**：
4. ✦ 款式說明（程式列出這次上架的顏色與尺碼）
5. ✦ 注意事項（依品類的固定文案：服飾／襪類）

**不寫**：賣場介紹、退換貨、推薦三款、Hook 三行標題、「本賣場」「歡迎選購」這類填充句。

## 4. 尺碼

- 第二軸尺碼標籤一律 **公斤**：`S（40-47.5kg）`。**絕對不可出現「斤」字**，也不要「斤 ‧ kg」並列
- 1688 的斤數由程式換算；廠商沒給就只寫 S/M/L，不自己估
