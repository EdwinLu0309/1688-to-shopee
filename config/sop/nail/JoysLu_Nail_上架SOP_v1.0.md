## 2. 標題

### 2.1 硬規則

- **上限 60 字**（含空格與符號）；目標 **58-60**，55-57 可接受，低於 55 要補詞
- 半形空格唯一分隔；**零符號**（不用【】、emoji、｜、！）
- 不放：免運／出貨／現貨／促銷詞、絕對化用語（最／第一／100%／保證）
- 英文型號照原文（`EN101MAX`、`SUN3`、`DC-Q1B`）
- 繁體，不可出現簡體、產地字眼、其他平台名

### 2.2 公式

```
[特色+品類詞] [型號] [規格差異點] [關鍵字尾串]
```

**開頭是「特色＋品類詞連寫」**，例如 `無線美甲吸塵器`、`空心杯磨甲機`、`雙渦輪集塵器`。
修飾詞必須是**可驗證的客觀特色**（功能／造型／形態／客群），禁形容詞（質感／方便／高階）。

⚠️⚠️ **開頭用哪個品類詞，看搜尋詞庫的實測量，不要憑語感**（2026-09-16 實測推翻原規範的預設）：

| 想寫 | 實測 | 該用 |
|---|---|---|
| 美甲打磨機 4,054 | **磨甲機 28,139** | `磨甲機`（差 7 倍） |
| 美甲集塵器（零量） | **美甲吸塵器 4,442** | `美甲吸塵器` |
| 美甲除塵器 0、美甲店專用 0 | — | 不要用 |

**同商品編號多支時，用不同的特色開頭**（型號保留完整不裁切），避免自家商品互相競爭同一個字串。

### 2.3 尾串由程式給，不要自己想

每次生成會附「**可用關鍵字**」清單與「**建議尾串**」——那是從搜尋詞庫讀的，已經排除三種詞：

- **泛用詞**（`過濾棉 11622` 是魚缸濾材、`分裝瓶 48203` 是化妝品、`打磨機 8184` 是木工）
  → 量大但客群不對，引進來只會拉低點擊率與轉換
- **品牌詞**（莎夏、愛美佳、infin.lin）→ 可投廣告，**不可寫進自家標題**（侵權／不實）
- **死詞**（`光撩燈 0`、`烘甲燈 5`）

**只能用清單裡的詞**。沒列的詞代表沒搜尋量或客群不對，不要自己發明。
字數不足 58 時，從清單往下補；補完仍不足就留著，**不要用形容詞灌水**。

### 2.4 規格詞的紀律（合規問題，不是文案問題）

⚠️⚠️ **標題裡每個規格數字（瓦數／燈珠／轉速／容量／片數）只能來自已驗證資料**：
規格名字串、名單填的欄位、廠商規格表。

**一個 1688 網址常常掛好幾款不同商品**（實測同一頁同時有「302吸塵打磨機二合一」
「G1S渦輪美甲吸塵器」「吸塵器濾網」），而**頁面標題描述的是最強那款**。
把頁面標題的瓦數寫到我們實際要賣的那款上，就是不實標示。

- 推測的規格 → **不要寫**
- 資料太薄（只知道形態、不知道瓦數）→ **寧短勿編**，用形態詞與尾串補字數
- 程式會逐支比對標題裡的數字是否找得到出處，對不上會擋下來

## 3. 詳情

八區塊那版是從 Lady 女裝抄來的，工具與耗材用不上（賣場介紹、退換貨蝦皮後台已統一設定）。
**現行五區塊**：

1. **開頭賣點** 3-5 行，本商品最強的 2-3 個賣點
2. **商品規格** 廠商有寫才列，**不腦補**；沒有的欄位直接不列，不要寫「詳見商品標示」
3. **使用方法** 器材：操作與保養要點；耗材：怎麼更換、相容機型
4. **款式說明** 這次賣的是哪一款、與同頁其他款的差別（一頁多款時特別重要）
5. **注意事項** 電器：電壓與清潔；光療品：避免接觸皮膚、孕婦慎用、避光存放

⚠️ 不要出現「本賣場」「歡迎選購」這類填充段落——那是版位浪費。

## 4. 禁用

- 醫療效果字眼（治療、修復指甲病變）
- 絕對化用語（最、第一、100%）
- 「現貨」只有訂貨需求＝現貨時可用；**預購品絕不可寫現貨／隔日到貨**
- 不可出現：淘寶、天貓、1688、代購、產地字眼
- **療字分流**：器材類可用「光療」；膠類一律「光撩」
